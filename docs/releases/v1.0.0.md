# django-liveclassroom 1.0.0

The first stable release of `django-liveclassroom`, a reusable Django teaching
package for live classrooms, reusable learning content, presentations, and
assessments.

## Highlights

- Reusable courses, classes, lessons, native slide decks, question banks,
  assessments, and named content sharing.
- Teacher-paced classrooms with guest or authenticated entry,
  open/waiting-room/roster admission, independent display and participant
  channels, chat, response control, and reconnect recovery.
- Practice, quiz, assignment, and timed-exam delivery with immutable snapshots,
  autosave, question pools and randomization, objective and manual grading,
  audited corrections, controlled result release, review, analytics, and
  CSV/JSON exports.
- Markdown/YAML and JSON portability, private Markdown/PDF/PowerPoint/video
  classroom files, presenter notes, and optional VaultPub content integration.
- Host extension points for authorization, rosters, content providers, grading,
  exports, AI authoring, and background work. AI output remains
  teacher-reviewed.
- Packaged English and Simplified Chinese interfaces, a standalone reference
  project, and mount-prefix-safe integration with existing Django projects.

## Requirements and deployment

- Python 3.12 or newer.
- Django 5.2 or 6.0.
- SQLite and the in-memory channel layer support local or simple single-process
  use.
- PostgreSQL with `LISTEN/NOTIFY` supports multi-worker production deployments.
- The release wheel and source distribution include the generated browser
  application; source checkouts can regenerate it with `bun run bundle`.

See `docs/usage.md` for installation, classroom and assessment workflows,
Django/ASGI integration, production configuration, security boundaries,
maintenance commands, and troubleshooting.

The bundled standalone settings are for local development. Production
deployments must provide their own secret, host and HTTPS settings, private
media/static serving, authorization policy, database, and ASGI process.
Optional VaultPub and AI integrations remain host-configured. An ordinary
browser is not a lockdown or remote-proctoring system.
