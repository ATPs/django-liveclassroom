教师快速指南

LiveClassroom 帮助

按下面的路径准备内容、开始课堂、交付测验和查看结果。每一步都说明了当前页面能做什么，以及还需要什么条件。

教师快速路径

  1. 准备组织：打开教师工作区，可选地创建 Course（课程主题）和 Class（学生班级）。保存的内容需要账号；即时课堂仍可让访客使用加入码进入。
  2. 编写内容：在教案编辑器添加活动，或导入 Markdown / YAML。要写幻灯片可打开幻灯片工作区；启用主机适配器后，可使用 VaultPub 的笔记和 Slide View。
  3. 共享或复制：在内容编辑器中使用共享控件，或从“与我共享”打开已授权内容。复制得到独立副本。
  4. 开始授课：回到教师工作区，从教案创建课堂，再在教师控制台开始课堂、发布活动和控制大屏/学生端。学生可从加入页面输入加入码。
  5. 创建测验：在测验编辑器选择题目、预览固定版本并发布。学生使用教师分享的测验链接开始或继续作答，答案会保存到其账号，完成后提交。
  6. 复盘结果：打开结果与评分，选择测验、提交和题目，或打开人工评分队列。学生从“我的作答与结果”查看教师已发布的结果。

简单默认设置

  • 组织关系是可选的；没有 Course 或 Class 也可以准备内容和开始即时课堂。
  • 保存教案、幻灯片和测验使用现有账号；现场课堂仍支持访客加入。
  • VaultPub 是启用后才可用的丰富笔记/幻灯片来源；AI 只生成待审核草稿，教师必须先审核和接受。
  • 高级考试设置在主要路径之外。示例数据只在你主动运行种子命令时创建，不会在启动时执行。

三个页面分别做什么

教师工作区

集中管理可复用教案、共享教案、班级和最近课堂，从这里决定新课堂使用哪份内容。

教案编辑器

创建和调整教案，添加活动、导入 Markdown / YAML、检查预览，并审核 AI 草稿后再接受。

教师控制台

课堂开始后启动、暂停或结束课堂，发布活动，管理准入，查看回答，并分别控制大屏和学生端。

发布、共享和结束前请确认

  • 发布按频道进行；发布到大屏不会自动发布到学生端。公开答案或解析前先检查当前频道。
  • 共享只授予指定账号；需要时撤销共享。复制后对方拥有独立内容，不能代替原作者。
  • 结束课堂会关闭新的作答和课堂聊天；归档保留记录，删除已归档课堂会永久移除它及其记录。

导航与返回

左侧导航可折叠为图标栏；手机上通过顶部按钮打开。教学和学习模式只显示你有权限访问的内容。课程、班级、题目和编辑面板可通过链接重新打开；浏览器返回和前进用于恢复浏览位置。未保存的编辑会提示保存、放弃或留在此页。返回不会撤销已发布活动，也不会暂停测验计时。

常见任务

创建可复用教案

打开教案编辑器，设置标题，添加活动或导入 Markdown / YAML、JSON，保存后回到工作区开始课堂。

创建即时课堂

在教师工作区选择即时课堂，填写信息并创建；进入控制台后确认加入码、准入方式和频道。

查看学生视角

从角色菜单选择“学生预览”，选择课堂后明确点击“开始测试学生”。打开页面、刷新或浏览器返回不会自动创建测试参与者。

页面状态、键盘和手机

列表为空时先确认账号、班级和筛选条件；加载中请等待页面提示；出现错误时保留输入并使用“重试”，不要重复提交已经成功的操作。按钮和链接可用 Tab、Shift+Tab 和 Enter 操作；手机上先横向滚动宽表格，课堂大屏适合桌面显示。

Teacher quick guide

LiveClassroom help

Follow this path to prepare content, start class, deliver an assessment, and review results. Each step states what is available now and what requires another setup.

Getting started

  1. Set up organization: Open the teacher workspace and optionally create a Course (subject) and Class (learner cohort). Saved content uses an account; an instant classroom still supports guest entry with a join code.
  2. Author content: Use the lesson builder to add activities or import Markdown / YAML. Use the slide-deck workspace for native slides. VaultPub note and Slide View rendering is available when the host adapter is enabled.
  3. Share or copy: Use the sharing controls in content editors, or open authorized content from Shared with me. Copying creates an independent copy.
  4. Teach: Return to the teacher workspace, create a classroom from a lesson, then start class, publish activities, and control the display and student channels in the console. Students can enter through the join page with the code.
  5. Create an assessment: Open the assessment builder to choose questions, preview pinned versions, and publish. Students use the run link you provide to start or resume; answers save to their account and can then be submitted.
  6. Review results: Open Results and grading, select an assessment, submission, and question, or open the manual grading queue. Students use My attempts and results to view results released by their teacher.

Simple defaults

  • Organization is optional; you can author content and start an instant classroom without a Course or Class.
  • Saved lessons, decks, and assessments use existing accounts; live classrooms still support guests.
  • VaultPub is an optional rich note/slide source. AI produces teacher-reviewed drafts only; a teacher must review and accept them.
  • Advanced exam controls stay outside the primary path. Demo data is created only by an explicit seed command and never during normal startup.

What each surface is for

Teacher workspace

Manage reusable lessons, shared lessons, classes, and recent classrooms. Choose the content that a new classroom should start from.

Lesson builder

Create and edit lessons, add activities, import Markdown / YAML, check the preview, and review AI drafts before accepting them.

Teacher console

Start, pause, or end class; publish activities; manage admission; review responses; and control display and student channels separately.

Check before publishing, sharing, or ending

  • Publishing is channel-specific: publishing to the display does not publish to students. Check the current channel before revealing answers or explanations.
  • Sharing grants access to a selected account. Revoke it when needed; a copy belongs to its recipient and does not replace the source.
  • Ending a classroom closes new responses and chat; archiving keeps the record, while deleting an archived classroom permanently removes it and its records.

Navigation and Back

Collapse the sidebar to an icon strip, or use the header button to open it on a phone. Teaching and Learning modes show permitted destinations. Links can reopen courses, classes, questions, and editor panels; browser Back and Forward restore browsing state. Unsaved editing offers Save, Discard, or Stay. Back never reverses a published activity or pauses an assessment timer.

Common tasks

Create a reusable lesson

Open the lesson builder, set a title, add activities or import Markdown / YAML or JSON, save it, then return to the workspace to start a classroom.

Create an instant classroom

Choose Instant classroom in the teacher workspace, enter the details, and check the join code, admission mode, and channels in the console.

Try the student view

Choose Student preview in the role menu, select a session, then explicitly select Start test student. Opening, refreshing, or returning to the page never starts test participation automatically.

Empty, loading, error, keyboard, and mobile guidance

When a list is empty, check the account, class, and filters. While loading, wait for the status message. If an error appears, keep the entered data and use “Retry” instead of repeating a completed action. Buttons and links work with Tab, Shift+Tab, and Enter; on a phone, scroll wide tables horizontally and use a desktop display for the classroom projector view.
